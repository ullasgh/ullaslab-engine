# Vendored geodata

`countries-110m.json` is copied unmodified from the npm package `world-atlas@2.0.2`
(https://github.com/topojson/world-atlas), a TopoJSON redistribution of Natural Earth 4.1.0
(1:110m Admin 0 countries).

- Natural Earth data: public domain (https://www.naturalearthdata.com/about/terms-of-use/). No attribution required.
- world-atlas packaging: ISC licence, copyright 2013-2019 Michael Bostock (`world-atlas.LICENSE`, kept with the file).

On-screen maps still carry a source stamp ("Natural Earth") because every visual carries one.
Country `id` values are ISO 3166-1 numeric codes (for example 356 = India, 156 = China, 840 = United States).
